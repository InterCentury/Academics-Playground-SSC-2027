This repository is where I store my **SSC (2027) study notes**.

I often use AI tools like **ChatGPT** and **Gemini** to generate notes from PDFs, books, or lectures.  
They do a great job turning long content into clean, well-structured explanations — but **saving those notes locally becomes messy very fast**.

Files get scattered, versions get confusing, and accessing them from different devices is inconvenient.

Using GitHub solves that problem for me.

Here, all notes are:
- written in Markdown
- organized by subject
- accessible from anywhere
- easy to update, fix, and improve over time
- able to include images directly from online sources

This repository is simply my centralized, low-maintenance place for keeping all my AI-assisted study notes in one clean system.
