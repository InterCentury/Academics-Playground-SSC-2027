# Chapter 2: গতি (Moiton)
```
            গতি ────┐
                    │
                    ├── সরলরৈখিক গতি
                    │   │
                    │   ├── দূরত্ব ── দ্রুতি ──> গড় দ্রুতি
                    │   │             └───>  তাৎক্ষণিক দ্রুতি
                    │   │
                    │   ├── সরণ ── বেগ ┬── সমবেগ
                    │   │               ├── অসমবেগ
                    │   │               ├── গড় বেগ
                    │   │               ├── তাৎক্ষণিক বেগ
                    │   │               │
                    │   │               ├── ত্বরণ ───> সুষম ত্বরণ
                    │   │               │        ├──> অসম ত্বরণ
                    │   │               │        └──> তাৎক্ষণিক ত্বরণ
                    │   │               │
                    │   │               └── মন্দন ── অসম মন্দন
                    │   │                       
                    │   │
                    │   ├── গতির সমীকরণ
                    │   │   │
                    │   │   ├── ত্বরণের ক্ষেত্রে
                    │   │   │   ├── v = u + at
                    │   │   │   ├── s = ((u + v) / 2)t
                    │   │   │   ├── s = ut + 1/2 at²
                    │   │   │   ├── v² = u² + 2as
                    │   │   │   └── sₜ = u + 1/2 a(2t - 1)
                    │   │   │
                    │   │   └── মন্দনের ক্ষেত্রে
                    │   │       ├── v = u - at
                    │   │       ├── s = ut - 1/2 at²
                    │   │       ├── v² = u² - 2as
                    │   │       └── sₜ = u - 1/2 a(2t - 1)
                    │   │
                    │   └── পড়ন্ত বস্তুর সূত্র
                    │       ├── ১ম সূত্র ── স্থির অবস্থান থেকে বিনা বাধায় পড়ন্ত সকল বস্তু
                    │       │              সমান সময়ে সমান পথ অতিক্রম করে।
                    │       ├── ২য় সূত্র ── v ∝ t
                    │       └── ৩য় সূত্র ── h ∝ t²
                    │
                    ├── রাশি
                    │    ├── স্কেলার রাশি ── তাপমাত্রা, সময়, দৈর্ঘ্য, ভর ইত্যাদি
                    │    └── ভেক্টর রাশি ── সরণ, বেগ, বল ইত্যাদি
                    │
                    ├── ঘূর্ণন গতি
                    │     ├── জটিল গতি ────── চলমান গাড়ির চাকার গতি
                    │     └── সরল ঘূর্ণন গতি ── ঘড়ির কাঁটার গতি, বৈদ্যুতিক পাখার গতি
                    │
                    ├── চলন গতি
                    │     ├── সরল চলন গতি ──── টেবিলের উপর বইয়ের গতি
                    │     └── বক্র চলন গতি ──── বক্রপথে বিমানের গতি
                    │
                    └── পর্যায়বৃত্ত গতি
                           ├── বৃত্তাকার পর্যায়বৃত্ত গতি ──── ফ্যানের পাখার গতি
                           ├── উপবৃত্তাকার পর্যায়বৃত্ত গতি ── সূর্যকে ঘিরে হ্যালির ধূমকেতুর গতি
                           ├── সরলরৈখিক পর্যায়বৃত্ত গতি ── স্প্রিংয়ে ঝুলিয়ে রাখা দুলতে থাকা বস্তু
                           └── সরল স্পন্দন গতি ───────── সরল দোলকের গতি

```
