

**প্রথম অধ্যায়: পূর্ব বাংলার আন্দোলন ও জাতীয়তাবাদের উত্থান ( ১৯৪৭ খ্রি. - ১৯৭০ খ্রি. )**

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অসাম্প্রদায়িক (Non-Communal Liberal) | যিনি ভিন্ন মত, আদর্শ বা সম্প্রদায়ের প্রতি সম্মান প্রদর্শন করেন এবং নাগরিকদের ব্যক্তিগত স্বাধীনতায় বিশ্বাস করেন। | ৫ |
| গণঅভ্যুত্থান (Mass Revolt) | কোনো এলাকা বা দেশের বহু সংখ্যক মানুষের ওই দেশের ক্ষমতাসীনদের বিরুদ্ধে তীব্র আন্দোলন করা। | ১০ |
| জনসভা (Public Meeting) | যখন একদল লোক একই উদ্দেশ্যে একটি নির্দিষ্ট স্থানে একত্রিত হয়। | ৩ |
| জাতীয়তাবাদ (Nationalism) | একই ধরনের ভাষা, সংস্কৃতি, আদর্শের অনুসারী বা নির্দিষ্ট ভূখণ্ডে বসবাসকারী জনগোষ্ঠীর মধ্যে বিদ্যমান গভীর ঐক্যবোধ। | ৪ |
| দাপ্তরিক ভাষা (Official Language) | যখন কোনো ভাষাকে অফিস, দেশ বা রাষ্ট্রে ব্যবহারের জন্য সাংবিধানিকভাবে স্বীকৃতি দেওয়া এবং এটি বলবৎ করা হয়। | ১ |
| ধনিকগোষ্ঠী (Rich Community) | যারা প্রচুর অর্থ-সম্পদের অধিকারী। | ১ |
| ধর্মঘট (Strike) | কোনো কিছুর প্রতিবাদস্বরূপ কর্মচারীদের কাজ করতে অস্বীকৃতি জানানো। | ২ |
| প্রগতিশীল (Progressive) | যে বা যারা সমাজে প্রচলিত কুসংস্কার নিরসনে নিজেদের জ্ঞান ও সামর্থ্য কাজে লাগায়। | ৫ |
| পিকেটিং (Picketing) | হরতাল বা ধর্মঘটের সময় কর্মসূচি বাস্তবায়নে কর্মকাণ্ড পরিচালনা এবং একইসাথে জনসাধারণের দৈনন্দিন স্বাভাবিক কাজে বাধা প্রদান। | ২ |
| বিক্ষোভ (Protest) | কোনো অন্যায়ের বিরুদ্ধে ব্যক্তি, দল বা প্রতিষ্ঠানের অশান্ত প্রতিবাদ বা আন্দোলন। | ৩ |
| বুদ্ধিজীবী (Intellectual) | যিনি সমাজ সম্পর্কিত বিভিন্ন জটিল চিন্তা, গবেষণা ও প্রভাব ইত্যাদি বিষয়ে বুদ্ধিবৃত্তিক কাজে জড়িত থাকেন এবং সমাজের বিভিন্ন সমস্যা সমাধানের উপায় বের করেন। | ২ |
| মিছিল (Procession) | যখন একদল লোক বা যানবাহন একই ধরন বা ছন্দ বজায় রেখে কোনো উদ্দেশ্যে একসাথে চলে। | ২ |
| রাজবন্দি (Political Prisoner) | মূলত রাজনৈতিক কারণে যাদেরকে কারাগারে বন্দি করা হয়। | ৬ |
| শোষণ (Exploitation) | নিজেদের স্বার্থ অর্জনে অন্য কোনো ব্যক্তি বা গোষ্ঠীর কাছ থেকে অবৈধভাবে সুবিধা আদায় এবং তাদের বঞ্চিত করা। | ১ |
| সশস্ত্র (Armed) | আগ্নেয়াস্ত্র দ্বারা সুসজ্জিত। | ১ |
| সার্বভৌমত্ব (Sovereignty) | রাষ্ট্রের চূড়ান্ত ক্ষমতা, যার মাধ্যমে রাষ্ট্র অভ্যন্তরীণ সকল ব্যক্তি ও প্রতিষ্ঠানের ওপর কর্তৃত্ব আরোপ করে এবং বহিঃশক্তির নিয়ন্ত্রণ ও হস্তক্ষেপ থেকে মুক্ত থাকে। | ৫ |
| সামরিক শাসন (Martial Law) | সর্বোচ্চ পর্যায়ের সামরিক কর্তা দ্বারা দেশ শাসন। | ৭ |
| স্বাধীনতা (Freedom) | নিজের ইচ্ছানুযায়ী কাজ করা, কথা বলা ও চিন্তা করার ক্ষমতা। | ১ |
| স্বায়ত্তশাসন (Autonomy) | স্বাধীনভাবে কার্যক্রম পরিচালনা করার ক্ষমতা। | ৬ |





**দ্বিতীয় অধ্যায়: বাংলাদেশের স্বাধীনতা**

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অধিবেশন (Conference) | কোনো নির্দিষ্ট বিষয়ে একদল মানুষের একটি আনুষ্ঠানিক সভায় অংশগ্রহণ করা, যা এক বা একাধিক দিন ধরে অনুষ্ঠিত হয়। | ১৪ |
| অভ্যুদয় (Emergence) | নতুনভাবে কোনো কিছু প্রকাশিত হওয়া। | ১৫ |
| অসহযোগ আন্দোলন (Non-Cooperation Movement) | দেশ শাসনে সরকারকে সহযোগিতা না করার আন্দোলন। | ১৪ |
| আত্মসমর্পণ (Surrender) | প্রতিপক্ষের বিরোধিতা বন্ধ করে তাদের কর্তৃপক্ষের কাছে নিজেকে নিবেদন করা। | ২৪ |
| গণহত্যা (Genocide) | কোনো জাতি বা গোষ্ঠীকে নির্মূল বা ধ্বংস করে দেওয়ার উদ্দেশ্যে পরিকল্পিতভাবে সেই জাতি বা গোষ্ঠীর বহু সংখ্যক মানুষকে হত্যা করা। | ১৯ |
| গেরিলা (Guerilla) | যিনি ছোট কোনো স্বাধীন দলের সদস্য হিসেবে ছদ্মবেশে অনিয়মিতভাবে কোনো নির্মিত বিশাল বাহিনীর বিরুদ্ধে যুদ্ধ করেন। | ১৭ |
| জাতীয় পরিষদ (National Assembly) | কোনো দেশের সকল প্রদেশ বা প্রশাসনিক অঞ্চল নিয়ে গঠিত পরিষদ। | ১৪ |
| নিরঙ্কুশ (Inevitable) | যাতে কোনো বাধা নেই, অনিবার্য বা নিশ্চিত। | ১৪ |
| নীল নকশা (Blueprint) | কোনো পরিকল্পনা বাস্তবায়নের নকশা বা কৌশল। | ১৬ |
| পটভূমি (Background) | কোনো ঘটনা বা অবস্থা সৃষ্টির পেছনের ঘটনা। | ১২ |
| প্রাদেশিক পরিষদ (Provincial Assembly) | কোনো দেশ বা রাষ্ট্রের একটি অংশবিশেষ তথা প্রদেশ বা প্রশাসনিক অঞ্চল নিয়ে গঠিত পরিষদ। | ১৪ |
| বীরাঙ্গনা (Heroic Woman) | সাধারণত সাহস, অসম্মান অর্জন বা মহৎ গুণাবলির জন্য প্রশংসিত নারী অথবা যুদ্ধক্ষেত্রের বীর নারীকে বোঝায়। এখানে বাংলাদেশ সরকার কর্তৃক মুক্তিযুদ্ধে সময় ধর্ষিত ও নির্যাতিত নারীদের দেওয়া খেতাবকে বোঝানো হয়েছে। | ২১ |
| ভেটো (Veto) | ভেটো অর্থ বিরোধিতা করা। মূলত জাতিসংঘের নিরাপত্তা পরিষদের স্থায়ী রাষ্ট্রগুলোর জাতিসংঘ ও অন্যান্য রাষ্ট্রের উত্থাপিত প্রস্তাব নাকচ করার ক্ষমতা। | ২১ |
| রাজাকার (Razakar) | ১৯৭১ সালে মুক্তিযুদ্ধের সময় পাকিস্তানি বাহিনীকে সহায়তার জন্য এদেশের স্বাধীনতা বিরোধীদের নিয়ে গঠিত একটি আধা-সামরিক বাহিনী। | ১৮ |
| শহীদ (Martyr) | সাধারণত ন্যায়-নীতির জন্য যিনি জীবন উৎসর্গ করেন তিনিই শহীদ। এখানে দেশ বা জাতির জন্য জীবন দেওয়াকে বোঝানো হয়েছে। | ১৮ |
| শরণার্থী (Refugee) | যারা যুদ্ধ, নির্যাতন বা প্রাকৃতিক বিপর্যয়ের কারণে নিজ দেশ ত্যাগ করে অন্য দেশে অস্থায়ীভাবে বসবাস করতে বাধ্য হন। | ১৯ |
| ষড়যন্ত্র (Conspiracy) | কোনো দল বা গোষ্ঠী কর্তৃক অবৈধ বা ক্ষতিকর কোনো কিছু করার গোপন পরিকল্পনা। | ১৪ |
| সর্বাধিনায়ক (Commander-in-Chief) | যার হুকুম বা নির্দেশে কোনো দেশের সশস্ত্র বাহিনী বা কোনো নির্দিষ্ট এলাকায় যুদ্ধরত সব বাহিনী পরিচালিত হয়। | ১৭ |
| স্বতঃস্ফূর্তভাবে (Spontaneously) | বাইরের কোনো চাপ বা প্রভাব ছাড়াই কোনো কিছু ঘটা। | ১৮ |
| হরতাল (Hartal) | কোনো দাবি আদায় করতে দোকান-পাট, অফিস-আদালত, যানবাহনসহ সব কর্মক্ষেত্র বন্ধ রেখে সরকারের বিরুদ্ধে জনগণের সম্মিলিত আন্দোলন। | ১২ |






**তৃতীয় অধ্যায়: সৌরজগৎ ও ভূমণ্ডল**

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| আগ্নেয়গিরি (Volcano) | এক ধরনের পাহাড়, যার ভেতর দিয়ে ভূ-গর্ভস্থ উত্তপ্ত গলিত পাথর, ছাই, গ্যাস ইত্যাদি বেরিয়ে আসে। | ২৬ |
| আর্দ্রতা (Humidity) | কোনো নির্দিষ্ট স্থানের বায়ুতে জলীয়বাষ্পের পরিমাণ। | ২৬ |
| আবর্তন (Rotation) | লাটিমের ভ্রমণ বা ঘূর্ণন। | ২৪ |
| উপবৃত্তাকার (Elliptic) | চ্যাপ্টা বৃত্ত বা ডিম্বাকার দেখতে এক ধরনের জ্যামিতিক আকৃতি। | ৩৪ |
| উল্কা (Meteor) | মহাকাশে পরিভ্রমণরত পাথর বা ধাতু দ্বারা গঠিত ছোট বস্তু, যা পৃথিবীর বায়ুমণ্ডলে প্রবেশ করলে বায়ুর সংঘর্ষে জ্বলে ওঠে। | ২৩ |
| কক্ষপথ (Orbit) | কোনো একটি বস্তুর কেন্দ্রমুখী বলের প্রভাবে অপর একটি বস্তুর চারদিকে ঘোরার পথ। | ৩৩ |
| গিরিখাত (Canyon) | খাড়া বাঁধ বা পর্বত শিখরের মধ্যে নদী প্রবাহের ফলে সৃষ্ট গভীর খাদ বা উপত্যকা। | ২৫ |
| ছায়াপথ (Galaxy) | মহাকাশীয় শক্তি দ্বারা আবদ্ধ অসংখ্য নক্ষত্র, গ্রহ, উপগ্রহ, ধূলিকণা, আন্তঃনাক্ষত্রিক গ্যাস ও অন্যান্য অদৃশ্য বস্তুর সমাবেশ। | ২৩ |
| জ্যোতিষ্ক (Astronomical Bodies) | মহাকাশে অবস্থিত সব ধরনের বস্তু। | ২৩ |
| তরঙ্গ (Wave) | বাতাস বা কম্পন বা সঞ্চালন হওয়া। এর ফলে সৃষ্টি হয় এক ধরনের ঢেউ, যা জড় মাধ্যমের এক স্থান থেকে অন্য স্থানে শক্তি সঞ্চার করে। | ২৭ |
| ধাতু (Metal) | যেসব মৌলিক পদার্থ সাধারণ অবস্থায় কঠিন, উজ্জ্বল এবং তাপ ও বিদ্যুৎ পরিবাহী। | ২৭ |
| ধূমকেতু (Comet) | ধুলো, বরফ ও গ্যাসের তৈরি এক ধরনের মহাজাগতিক বস্তু, যা সূর্যের খুব নিকট দিয়ে পরিভ্রমণ করার সময় একটি পাতলা ঝাড়ু আকৃতির বায়ুমণ্ডল এবং দীর্ঘ লেজ প্রদর্শন করে। | ২৩ |
| নক্ষত্র (Star) | মহাকাশে অবস্থিত বিশাল আকারের গ্যাসের অত্যন্ত উজ্জ্বল জ্বলন্ত কুন্ডলী। | ২৩ |
| নীহারিকা (Nebula) | ধুলিকণা, হাইড্রোজেন গ্যাস এবং প্লাজমা দ্বারা গঠিত এক ধরনের আন্তঃনাক্ষত্রিক মেঘ। | ২৩ |
| পরিধি (Circumference) | একটি বৃত্তাকার এলাকার বা আবদ্ধ ক্ষেত্রফলের বাইরের সীমানা বরাবর দৈর্ঘ্য। | ২৮ |
| বলয় (Ring) | মহাবিশ্বের কোনো বস্তুর চারপাশে একটি নির্দিষ্ট চ্যাপ্টা আকৃতির অঞ্চলে আবর্তনরত ধূলি ও ছোট ছোট কণার বেষ্টনী। | ২৬ |
| ব্যাস (Diameter) | বৃত্তের কেন্দ্র দিয়ে অতিক্রমকারী দুই পাশের সংযোগকারী সরলরেখা। | ২৪ |
| মরিচা (Rust) | জলীয় বাষ্প ও অক্সিজেনের সংস্পর্শে এসে বিক্রিয়ার মাধ্যমে লোহার ওপর যে লালচে বাদামি আস্তরণ পড়ে। | ২৫ |
| গ্রহাণুপুঞ্জ (Asteroids) | ১.৬ কি.মি. থেকে ৮০২ কি.মি. ব্যাসসম্পন্ন জ্যোতিষ্ককে গ্রহাণু বলে। আর এসব গ্রহাণুকে একত্রে গ্রহাণুপুঞ্জ বলে। | ২৩ |
| বুধ (Mercury) | সূর্য সূর্যের নিকটতম গ্রহ বলে এর তাপমাত্রা অত্যধিক। এত উচ্চ তাপমাত্রায় জীব বসবাস করতে পারে না। | ২৪ |
| শুক্র (Venus) | সূর্য থেকে দূরত্বের দিক দিয়ে শুক্রের তাপমাত্রা অত্যধিক। এছাড়াও পৃথিবীর মতো শুক্রের একটি বায়ুমণ্ডল থাকলেও এতে অক্সিজেন নেই। এ কারণে এতে কোনো জীব বসবাস করতে পারে না। | ২৪ |
| পৃথিবী (Earth) | পৃথিবী সৌরজগতের একটি গ্রহ। এটি সূর্য থেকে ১৫ কোটি কি.মি. দূরে অবস্থিত। জীবনধারণের জন্য প্রয়োজনীয় প্রায় সকল উপাদান যেমন বায়ু, জল, অক্সিজেন ইত্যাদি পর্যাপ্ত পরিমাণে থাকায় পৃথিবী নামক গ্রহে জীবজগতের বাসযোগ্য পরিবেশ বিদ্যমান। | ২৪ |
| মঙ্গল (Mars) | মঙ্গলের বায়ুমণ্ডলে শতকরা ৩ ভাগ নাইট্রোজেন ও শতকরা ২ ভাগ আর্গন গ্যাস আছে। পানির পরিমাণ খুবই কম। জীবনধারণের প্রয়োজনীয় অক্সিজেন নেই। তাই এখানে জীবনধারণ অসম্ভব। | ২৫ |
| প্রমাণ সময় (Standard Time) | প্রত্যেক দেশেই সেই দেশের মধ্যভাগের কোনো স্থানের দ্রাঘিমারেখা অনুযায়ী যে সময় নির্ধারণ করা হয় সে সময়কে ওই দেশের প্রমাণ সময় বলে। | ৩০ |
| গুরুমন্ডল (Barysphere) | কেন্দ্রমণ্ডলের উপর থেকে চতুর্দিকে প্রায় ২৮৮৫ কি.মি. পর্যন্ত গুরুমন্ডল বলে। সিলিকন, ম্যাগনেসিয়াম প্রভৃতি ভারী ধাতুগুলোর সমন্বয়ে গুরুমন্ডল গঠিত। | ২৭ |
| ইউরেনাস (Uranus) | সূর্য থেকে এর দূরত্ব ২৮৭ কোটি কিলোমিটার। এর বায়ুমণ্ডলে মিথেন গ্যাসের পরিমাণ অধিক। এখানে কোনো প্রাণের অস্তিত্ব নেই। | ২৬ |
| নেপচুন (Neptune) | সূর্য থেকে নেপচুনের দূরত্ব ৪৫০ কোটি কিলোমিটার। সূর্য হতে অধিক দূরত্বের কারণে গ্রহটি অতিশয় শীতল। ফলে এখানে প্রাণের অস্তিত্ব অসম্ভব। | ২৬ |
| অনুসূর (Perihelion) | সূর্যের চারদিকে কোনো গ্রহের কক্ষপথের নিকটতম বিন্দুকে ঐ গ্রহের অনুসূর বলে। জানুয়ারির ১ থেকে ৩ তারিখের মধ্যে পৃথিবী এই অবস্থানে থাকে। | ৩৬ |
| অপসূর (Aphelion) | সূর্যের চারদিকে কোনো গ্রহের কক্ষপথের দূরতম বিন্দুকে ঐ গ্রহের অপসূর বলে। জুলাই মাসের ৪ থেকে ৬ তারিখের মধ্যে পৃথিবী এই অবস্থানে থাকে। | ৩৬ |
| প্রতিপাদ স্থান (Antipode) | ভূপৃষ্ঠের উপর অবস্থিত কোনো বিন্দুর বিপরীত বিন্দুকে সেই বিন্দুর প্রতিপাদ স্থান বলে। | ৩১ |
| আন্তর্জাতিক তারিখ রেখা (International Date Line) | কোনো নির্দিষ্ট স্থান থেকে পূর্ব বা পশ্চিমে ১৮০ ডিগ্রি অতিক্রম করলে সময়ের সাথে সাথে দিন ও তারিখ পরিবর্তিত হয়। এই ১৮০ ডিগ্রি রেখাকেই আন্তর্জাতিক তারিখ রেখা বলা হয়। | ৩১ |
| দ্রাঘিমারেখা (Meridians of Longitude) | নিরক্ষরেখাকে ডিগ্রি, মিনিট ও সেকেন্ডে ভাগ করে প্রত্যেক ভাগের উপর দিয়ে উত্তর মেরু থেকে দক্ষিণ মেরু পর্যন্ত যে রেখাগুলো কল্পনা করা হয় তাকে দ্রাঘিমারেখা বলে। | ২৮ |
| সৌরকলঙ্ক (Sun Spot) | সূর্যের মধ্যে মাঝে মাঝে যে কালো দাগ দেখা যায় তাকে সৌরকলঙ্ক বলে। ১৬১১ সালে গ্যালিলিও প্রথম টেলিস্কোপের সাহায্যে সৌরকলঙ্ক প্রত্যক্ষ করেন। | ২৪ |
| অধিবর্ষ (Leap year) | পৃথিবী সূর্যকে একবার প্রদক্ষিণ করতে যে সময় নেয় তাকে এক সৌরবছর বলা হয়। সাধারণ বছরের ৩৬৫ দিন ৬ ঘণ্টার এই অতিরিক্ত ৬ ঘণ্টা সমন্বয় করার জন্য প্রতি ৪ বছর অন্তর ফেব্রুয়ারি মাসে একদিন বাড়িয়ে বছরটিকে ৩৬৬ দিনে গণনা করা হয়। একেই অধিবর্ষ বলা হয়। | ৩৬ |
| কেন্দ্রাতিগ শক্তি (Centrifugal Force) | পৃথিবী তার অক্ষ বা মেরুরেখার ওপর প্রতিনিয়ত পশ্চিম থেকে পূর্ব দিকে আবর্তন করছে। এই আবর্তনের ফলে পৃথিবীর কেন্দ্রের বিপরীত দিকে যে শক্তির সৃষ্টি হয় তাকে কেন্দ্রাতিগ শক্তি বলে। | ৩৭ |
| আহ্নিক গতি (Diurnal Motion) | পৃথিবী নিজের অক্ষের ওপর প্রতিদিন একবার আবর্তন করাকে পৃথিবীর আহ্নিক গতি বলে। পৃথিবীর এই আবর্তনের ফলে দিন ও রাত সংঘটিত হয়। | ৩৩ |
| বার্ষিক গতি (Annual Motion) | পৃথিবী তার নিজ কক্ষপথে অনবরত সূর্যের চারদিকে ঘুরছে। এই গতিকে বার্ষিক গতি বলে। পৃথিবীর এই গতির কারণে ঋতু পরিবর্তন ঘটে। | ৩৪ |
| জোয়ার-ভাটা (Ebb and Flow) | চন্দ্র ও সূর্য ভূপৃষ্ঠের জল এবং স্থলভাগকে অবিরাম আকর্ষণ করে। এই আকর্ষণের ফলে সমুদ্রের জলরাশি নির্দিষ্ট সময় অন্তর ফুলে ওঠে এবং নেমে যায়। জলের এই ফুলে ওঠাকে জোয়ার এবং নেমে যাওয়াকে ভাটা বলে। | ৩৬ |
| মানচিত্র (Map) | কোনো স্থানের ভূসংস্থান বা প্রাকৃতিক ও সামাজিক বিষয়সমূহকে স্কেল ও সংকেতের মাধ্যমে সমতল কাগজের ওপর উপস্থাপন করাকে মানচিত্র বলে। | ২৮ |

| ব-দ্বীপ (River Delta) | নদীর মোহনায় কাদা, পলি, বালি প্রভৃতি সঞ্চিত হয়ে মাত্রা হীন ‘ব’ অক্ষর আকৃতির সৃষ্ট দ্বীপ। | ৪২ |
| বাস্তুহারা (Refugee) | যুদ্ধ, নির্যাতন বা প্রাকৃতিক দুর্যোগের কারণে ঘরবাড়ি হারিয়ে অন্যস্থানে বসবাস করছেন এমন ব্যক্তি। | ৫১ |
| বায়ুচাপ (Atmospheric Pressure) | কোনো বস্তু বা পৃষ্ঠের একক ক্ষেত্রফলের ওপর পৃথিবীর বায়ু দ্বারা প্রযুক্ত বল। | ৪৭ |
| সমভাবাপন্ন (Equable) | সব সময় প্রায় একই রকম থাকে এমন। | ৪২ |
| সমভূমি (Plain Land) | সমুদ্রপৃষ্ঠের সাথে প্রায় সমতল বা বিশিষ্ট বিস্তীর্ণ এবং মৃদু ঢাল বিশিষ্ট বিস্তৃত ভূমি। | ৪২ |







**পঞ্চম অধ্যায়: বাংলাদেশের নদ-নদী ও প্রাকৃতিক সম্পদ**

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| উৎপত্তিস্থল (Place of Origin) | যে স্থান থেকে সৃষ্টি হয়েছে। | ৫৮ |
| উপনদী (Tributary) | যখন কোনো ক্ষুদ্র জলধারা বা নদী অপর একটি নদীতে পতিত হয়। | ৫৯ |
| জলপ্রপাত (Waterfall) | একটি নির্দিষ্ট উচ্চতা থেকে প্রাকৃতিকভাবে বহমান জলের প্রবলবেগে পতন। | ৬৩ |
| টারবাইন (Turbine) | এমন একটি ঘূর্ণায়মান যন্ত্র, যা গতিশক্তি ও তাপশক্তিকে যান্ত্রিক শক্তিতে পরিণত করে। | ৬৩ |
| নদীমাতৃক (Riverine) | নদীর মাধ্যমে যে দেশ উর্বর এবং শস্যসমৃদ্ধ। | ৫৮ |
| নবায়নযোগ্য শক্তি (Renewable Energy) | যে শক্তির উৎসকে বারবার ব্যবহার করা যায়। | ৬৩ |
| নাব্য (Navigable) | নৌকা বা জাহাজ চালানোর উপযুক্ত অবস্থা। | ৬০ |
| নিষ্কাশন (Extraction) | কোনো কিছু বের করে নেওয়া বা দূর করা। | ৬০ |
| পুষ্টিহীনতা (Malnutrition) | দেহে প্রয়োজনীয় পুষ্টির অভাব। | ৬২ |
| বিলুপ্ত (Extinct) | সম্পূর্ণ লোপ পেয়েছে বা নিশ্চিহ্ন হয়ে গেছে এমন। | ৬২ |
| মোহনা (Estuary) | যে স্থানে একটি নদী বা সাগরের সাথে অন্য একটি বা একাধিক নদী মিলিত হয়। | ৫৯ |
| শাখানদী (Distributary) | মূল নদী থেকে কোনো নদী বেরিয়ে এলে তাকে শাখানদী বলা হয়। | ৫৯ |
| সমুদ্র বন্দর (Sea Port) | সমুদ্র উপকূল বা সৈকতের এমন একটি স্থান, যেখানে জাহাজ নোঙর করে মালামাল ওঠানামা করতে পারে। | ৬০ |
| সরোবর (Lake) | বিশাল আকারের দিঘি বা হ্রদ। | ৫৯ |
| হিমবাহ (Glacier) | বরফের বিশাল চলমান স্তূপ বা নদী। | ৫৮ |

**ষষ্ঠ অধ্যায়: রাষ্ট্র, নাগরিকতা ও আইন**

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| আইনসভা (Legislature) | দেশের আইন প্রণয়ন, পরিবর্তন ও সংশোধনের কর্তৃত্বসম্পন্ন পরিষদ। | ৭৪ |
| আদিম (Ancient) | অতি প্রাচীনকালের। | ৭১ |
| কূটনৈতিক (Diplomatic) | কৌশলপূর্ণ বা কৌশলগত। কোনো রাষ্ট্র বা রাষ্ট্র সম্পর্কিত প্রতিষ্ঠানগুলোর মাঝে পারস্পরিক চুক্তি বা আলোচনা সম্পর্কিত কলাকৌশল। | ৭৪ |
| খাজনা (Tax) | কোনো জমি ভোগ দখলের জন্য প্রতিবছর সরকারকে যে নির্দিষ্ট পরিমাণ টাকা দিতে হয়। | ৭৪ |
| গবেষণা (Research) | মানুষের জ্ঞানের ভাণ্ডার বৃদ্ধির লক্ষ্যে কোনো বিষয়ে সুশৃঙ্খল ও বুদ্ধিবৃত্তিক অনুসন্ধান প্রক্রিয়া। | ৭৫ |
| দাতব্য চিকিৎসালয় (Charitable Dispensary) | জনসেবামূলক উদ্দেশ্যে নিয়ে চিকিৎসা সেবা দিয়ে থাকে এমন অলাভজনক চিকিৎসালয়। | ৭৪ |
| দুর্নীতি (Corruption) | ব্যক্তি বা গোষ্ঠী কর্তৃক অবৈধ উপায়ে নীতি-বহির্ভূত বা জনস্বার্থবিরোধী কাজ। | ৭৫ |
| দুর্ভিক্ষ (Famine) | কোনো এলাকায় ব্যাপক খাদ্যঘাটতি। | ৭৫ |
| নিরক্ষরতা (Illiteracy) | অক্ষর জ্ঞানের অভাব। | ৭৬ |
| বাজেট (Budget) | কোনো নির্দিষ্ট সময়ে সরকারের আয় ও ব্যয়ের হিসাব। | ৭৪ |
| ভর্তুকি (Subsidy) | কোনো জিনিসের নির্ধারিত মূল্য পুরোপুরিভাবে আদায় না হলে যতটুকু বাকি থাকে তা অন্য উৎস থেকে পরিশোধ করা। | ৭৫ |
| ভোট (Vote) | কোনো বিষয়ে ব্যক্তির নিজস্ব মতামত জানানো কিংবা জনমত প্রতিফলনের একটি বিশেষ পদ্ধতি। | ৭৭ |
| মহামারি (Epidemic) | কোনো নির্দিষ্ট এলাকায় নির্দিষ্ট সময়ে কোনো সংক্রামক রোগ ব্যাপকভাবে ছড়িয়ে পড়া। | ৭৬ |
| মুদ্রাস্ফীতি (Inflation) | এমন একটি অবস্থা যখন আশঙ্কাজনকভাবে দ্রব্যমূল্য বৃদ্ধি পায় এবং অর্থের ক্রয়ক্ষমতা ক্রমাগত হ্রাস পায়। | ৭৪ |
| সর্বজনীন (Universal) | যা সবার ওপর প্রযোজ্য। | ৭১ |
| সমাজ (Society) | পরস্পর নির্ভরশীল এবং সঙ্ঘবদ্ধভাবে বসবাসকারী জনসমষ্টি। | ৭১ |
| সুশাসন (Good Governance) | যে শাসন ব্যবস্থায় আইনের শাসন, দায়বদ্ধতা, স্বচ্ছতা ও নাগরিকদের অধিকারসমূহ গণতান্ত্রিক উপায়ে সুনিশ্চিত করা হয়। | ৭৯ |
| তহবিল (Exchequer) | রাষ্ট্রের মওজুদকৃত বা সঞ্চিত নগদ অর্থ। | ৮৭ |
| দেওয়ানি মামলা (Civil Case) | আইনগত অধিকার বা মর্যাদা রক্ষার্থে ব্যক্তি, গোষ্ঠী বা প্রতিষ্ঠান কর্তৃক দায়েরকৃত মামলা। | ৮৮ |
| ন্যায়পাল (Ombudsman) | আইনসভা কর্তৃক নিযুক্ত কর্মকর্তা, যিনি সরকারি সংস্থা বা কর্মকর্তাদের বিরুদ্ধে উত্থাপিত অভিযোগের তদন্ত করেন। | ৮৭ |
| পদসোপান (Hierarchy) | পদ বা মর্যাদার ক্রমানুসারে বিন্যাস। | ৮৩ |
| প্রজাতন্ত্র (Republic) | এমন একটি শাসনব্যবস্থা যেখানে জনগণ সর্বোচ্চ ক্ষমতা ভোগ করে। | ৮৪ |
| প্রবিধান (Regulation) | সংবিধানে প্রদত্ত ক্ষমতাপ্রাপ্ত ব্যক্তি বা কর্তৃপক্ষ কর্তৃক প্রণীত বিধান। | ৮৭ |
| প্রশাসন (Administration) | কোনো রাষ্ট্র, প্রতিষ্ঠান বা সংস্থার পরিচালনা বা ব্যবস্থাপনা। | ৮৩ |
| প্রহিবিশন রিট (Writ of Prohibition) | হাইকোর্ট যখন নিম্ন আদালতকে তার এখতিয়ার বহির্ভূত কোনো মামলার ব্যাপারে সিদ্ধান্ত না দেওয়ার আদেশ দেয়। | ৮৯ |
| ফৌজদারি মামলা (Criminal Case) | সাধারণত চুরি, ডাকাতি, খুন, জালিয়াতি বা শান্তি ভঙ্গকারী অপরাধের বিরুদ্ধে দায়েরকৃত মামলা। | ৮৮ |
| মুলতবি (Adjourn) | পরবর্তীকালে আবার চালু করা হবে এই উদ্দেশ্যে কোনো সভা স্থগিত করা। | ৮৭ |
| মৌলিক অধিকার (Fundamental Rights) | নাগরিকদের ব্যক্তিত্বের পরিপূর্ণ বিকাশের জন্য যেসব অধিকার সংবিধানে উল্লেখ থাকে এবং রাষ্ট্র কর্তৃক স্বীকৃত। | ৮৯ |
| ম্যান্ডামাস রিট (Writ of Mandamus) | কোনো সরকারি সংস্থা আইন অনুযায়ী কাজ করতে গাফিলতি করলে হাইকোর্ট থেকে ঐ সংস্থাকে সঠিক কাজ করার যে আদেশ দেওয়া হয়। | ৮৯ |
| রিট (Writ) | আদালত বা যথাযথ কর্তৃপক্ষ কর্তৃক ঘোষিত বিধান বা আদেশ। | ৮৯ |
| সরকার (Government) | কোনো দেশের সর্বোচ্চ সংস্থা ও কর্তৃপক্ষ, যার মাধ্যমে দেশের শাসনকার্য পরিচালিত হয়। | ৮৪ |
| সার্টিওরা রিট (Writ of Certiorari) | হাইকোর্ট যখন কোনো নিম্ন আদালতের রায়কে অবৈধ ঘোষণা করে বা ঐ আদালত থেকে কোনো মামলার নথি তলব করে। | ৮৯ |
| স্পিকার (Speaker) | যিনি সংসদ অধিবেশনের কার্যক্রম পরিচালনা করেন। | ৮৭ |
| হেবিয়াস কর্পাস রিট (Writ of Habeas Corpus) | কোনো ব্যক্তিকে অন্যায়ভাবে কারারুদ্ধ করে রাখা হলে আদালত থেকে ঐ ব্যক্তিকে আদালতে হাজির করার জন্য যে আদেশ দেওয়া হয়। | ৮৯ |

##  সপ্তম অধ্যায়: বাংলাদেশ সরকারের বিভিন্ন অঙ্গ ও প্রশাসন ব্যবস্থা  

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অধ্যাদেশ (Ordinance) | রাষ্ট্রপতি বিশেষ ক্ষমতাবলে যে আদেশ বা আইন জারি করেন। | ৮৫ |
| অনাস্থা প্রস্তাব (Vote of no Confidence) | এমন একটি ভোট বা প্রস্তাব, যার মাধ্যমে কোনো নির্দিষ্ট ব্যক্তি, গোষ্ঠী বা বিষয়ে সমর্থন না করা বোঝানো হয়। | ৮৮ |
| অভিশংসন (Impeachment) | এমন একটি প্রক্রিয়া, যার মাধ্যমে আইন বিভাগ রাষ্ট্রের কোনো সরকারি কর্মকর্তা বা রাষ্ট্রপতির বিরুদ্ধে অভিযোগ উত্থাপনের মাধ্যমে তাকে অপসারণ করতে পারে। | ৮৭ |
| অ্যাটর্নি জেনারেল (Attorney General) | সরকারের প্রধান আইন কর্মকর্তা বা আইনগত পরামর্শক। | ৮৪ |
| আমলা (Bureaucrat) | রাষ্ট্রপ্রধান ও মন্ত্রিসভার নিচে শাসন বিভাগের যেসব স্থায়ী সরকারি কর্মচারী দায়িত্ব পালন করেন। | ৮৩ |
| কূটনীতিক (Diplomat) | যিনি কোনো দেশের প্রতিনিধি হিসেবে অন্য কোনো দেশ বা আন্তর্জাতিক সংস্থার সাথে কূটনৈতিক বা কৌশলগত কার্যক্রম পরিচালনা করেন। | ৮৪ |
| কো ওয়ারেন্টো রিট (Writ of Quowarranto) | কারণ দর্শাও রিট। আদালত যখন কোনো কাজের ক্ষেত্রে কারো কাছে জানতে চায় যে, কোন অধিকারের বলে তিনি কাজটি করছেন। | ৮৯ |
| ট্রাইব্যুনাল (Tribunal) | সংবিধান বা অন্য কোনো আইন দ্বারা গঠিত এক ধরনের বিশেষ বিচারিক প্রতিষ্ঠান, যা নির্দিষ্ট কিছু বিষয় নিষ্পত্তিতে কাজ করে। | ৮৫ |

## অষ্টম অধ্যায়: বাংলাদেশের গণতন্ত্র ও নির্বাচন ব্যবস্থা 

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অনুশাসন (Discipline) | জনসাধারণের আইন বা আচার-আচরণ মেনে চলার অনুশীলন। | ৯৮ |
| উপ-নির্বাচন (By-election) | সংসদ বা অন্য কোনো পরিষদের কোনো সদস্যের মৃত্যু হলে, পদত্যাগ করলে বা অযোগ্য ঘোষিত হলে তার শূন্য আসন পূরণ করতে যে নির্বাচন অনুষ্ঠিত হয়। | ১০৩ |
| গণঅসন্তোষ (Mass dissatisfaction) | কোনো বিষয়ে সাধারণ বা জনগোষ্ঠীর ক্ষোভ বা অসন্তুষ্টি। | ৯৯ |
| দ্বৈতশাসন (Diarchy) | এক ব্যক্তি বা সংস্থা ক্ষমতা ভাগাভাগি করে একই সময়ে দুই শাসকতর শাসন। | ৯৮ |
| নির্বাচন কমিশন (Election Commission) | যে প্রতিষ্ঠান বা সংস্থা কোনো দেশের নির্বাচনী প্রক্রিয়া বাস্তবায়ন ও তদারকি করে। | ১০২ |
| নির্বাচনী তফসিল (Election Schedule) | নির্বাচন অনুষ্ঠানের জন্য নির্বাচন কমিশন কর্তৃক ঘোষিত কর্মপরিকল্পনা। | ১০২ |
| পোলিং অফিসার (Polling Officer) | নির্বাচনের দিন ভোটকেন্দ্রে যিনি কোনো প্রার্থীর পক্ষে নির্বাচন পর্যবেক্ষণের দায়িত্বে থাকেন। | ১০২ |
| প্রাপ্তবয়স্ক (Adult) | পরিণত বয়স হয়েছে এমন ব্যক্তি সাধারণত ১৮ বছর বা তার বেশি বয়সের ব্যক্তিকে বোঝায়। | ১০১ |
| প্রিসাইডিং অফিসার (Presiding Officer) | নির্বাচনের সময় ভোটকেন্দ্রের দায়িত্বে নিয়োজিত কর্মকর্তা। | ১০২ |
| বাকস্বাধীনতা (Freedom of Speech) | ব্যক্তি বা সম্প্রদায়ের নিজস্ব কোনো বক্তব্য অনুমতি গ্রহণ ছাড়াই নিজেদের মতামত প্রকাশের স্বাধীনতা। | ৯৮ |
| ব্যালট (Ballot) | গোপন ভোটদানে ব্যবহৃত নির্দিষ্ট কাগজ যেখানে পদপ্রার্থীর তালের ভোট দেয়। | ১০২ |
| মনোনয়নপত্র (Nomination Paper) | কোনো ব্যক্তির যাদ্ধাভুক্ত একটি কাগজ বা ফরম, যা নির্বাচনে ওই ব্যক্তির প্রার্থীত্বকে নিশ্চিত করে। | ১০২ |
| রিটার্নিং অফিসার (Returning Officer) | কোনো নির্দিষ্ট এলাকা বা জেলায় নির্বাচনী দায়িত্বে নিয়োজিত কর্মকর্তা। | ১০২ |
| লিফলেট (Leaflet) | কোনো সুনির্দিষ্ট বিষয়ে তথ্যসংবলিত এক টুকরো কাগজ বা ছোট বই। | ১০৫ |
| সামন্ততান্ত্রিক শাসন (Feudal Rule) | যে শাসন ব্যবস্থায় কেন্দ্রীয় শাসনের পরিবর্তে স্থানীয় ভূ-স্বামীদের মধ্যে রাজনৈতিক ও প্রশাসনিক ক্ষমতা ভাগ করে দিয়ে রাষ্ট্র বা রাজ্য পরিচালনা করা হয়। | ৯৪ |
| স্বৈরতান্ত্রিক শাসন (Autocratic Rule) | কোনো শাসক যখন দেশের জনগণ, সংবিধান, রীতিনীতি প্রভৃতি উপেক্ষা করে তার ইচ্ছানুযায়ী একক নির্দেশনায় দেশ শাসন করেন। | ৯৮ |
| হ্যান্ডবিল (Handbill) | একটি ছোট কাগজে মুদ্রিত বিজ্ঞাপন বা নোটিশ, যা মানুষের হাতে হাতে বিতরণ করা হয়। | ১০৫ |

## নবম অধ্যায়: জাতিসংঘ ও বাংলাদেশ

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অভূতপূর্ব (Unprecedented) | যা আগে কখনো দেখা যায়নি বা ঘটেনি। | ১১১ |
| অনুপ্রবেশ (Debut) | কোনো কিছু আনুষ্ঠানিকভাবে প্রথম প্রকাশ। | ১০৮ |
| কার্যপ্রণালী (Procedure) | কোনো কিছু করার আনুষ্ঠানিক উপায় বা পদ্ধতি। | ১০৯ |
| পক্ষপাতিত্ব (Bias) | অন্যায়ভাবে কারো বা কোনো কিছুর পক্ষে বা বিপক্ষে অবস্থান নেওয়া। | ১১১ |
| মধ্যস্থতাকারী (Mediator) | এমন ব্যক্তি যিনি একাধিক ব্যক্তি, রাষ্ট্র বা প্রতিষ্ঠানের মধ্যকার বিবাদ মীমাংসা করতে চেষ্টা করেন। | ১০৭ |
| মহাপরিচালক (Secretary General) | কোনো সংস্থা বা সংগঠনের প্রধান প্রশাসক। | ১০৭ |
| মানবাধিকার (Human Rights) | মানুষের ব্যক্তিত্বের সুষ্ঠু বিকাশ ও মর্যাদাপূর্ণ জীবন যাপনের জন্য অত্যাবশ্যকীয় সুযোগ-সুবিধাসমূহ। | ১০৭ |
| মিশন (Mission) | নির্দিষ্ট কাজ সম্পন্ন করার জন্য যখন কোনো দেশ বা সংস্থা কর্তৃক অন্য দেশে নিযুক্ত বাহিনী। | ১০৮ |
| লক্ষ্যমাত্রা (Goals) | কোনো কিছু অর্জন করার উদ্দেশ্য বা প্রচেষ্টা। | ১০৯ |
| লীগ অফ নেশনস (League of Nations) | প্রথম বিশ্বযুদ্ধের পর ১৯২০ সালে বিশ্বশান্তি প্রতিষ্ঠার জন্য বিভিন্ন দেশের সমন্বয়ে গঠিত আন্তর্জাতিক সংস্থা। | ১০৭ |
| সনদ (Charter) | কোনো সংগঠন বা জনসমষ্টির অধিকার, লক্ষ্য বা নীতি বর্ণিত রয়েছে এমন আনুষ্ঠানিক প্রমাণপত্র বা দলিল। | ১১০ |
| সম্মেলন (Conference) | কোনো বিশেষ স্বার্থে এক বা একাধিক দিন ধরে সংঘটিত আনুষ্ঠানিক সভা। | ১০৭ |
| সংস্থা (Organization) | এমন প্রতিষ্ঠান বা সংগঠন, যা একটি বিশেষ উদ্দেশ্য অর্জনের জন্য এক বা একাধিক ব্যক্তি, প্রতিষ্ঠান বা রাষ্ট্রের সমন্বয়ে গঠিত। | ১০৭ |
| সুবিধাবঞ্চিত (Underprivileged) | সমাজের বেশিরভাগ মানুষের মতো সমান অধিকার ও সুবিধা ভোগ করতে পারছে না এমন ব্যক্তি বা গোষ্ঠী। | ১১০ |
| সেমিনার (Seminar) | কোনো কিছু আলোচনা করা বা প্রশিক্ষণের জন্য অনুষ্ঠিত সভা। | ১১৩ |
| অভীষ্ট (Intended) | কাঙ্ক্ষিত ইচ্ছা। কোনো বস্তু পাওয়ার বা কোনো কাজ করার তীব্র ইচ্ছা এবং প্রচেষ্টা। | ১১২ |
| অংশীদারিত্ব (Partnership) | কোনো কার্যক্রমে যার যা দায়িত্ব ও কর্তব্য সুষ্ঠু অংশগ্রহণের মাধ্যমে তা পালন করা। | ১১৩ |
| জীবাশ্ম জ্বালানি (Fossil Fuels) | কোটি কোটি বছর পূর্বে গাছপালা ও জীবজন্তু প্রচণ্ড ভূকম্পন বা প্রাকৃতিক বিপর্যয়ের কারণে মাটি চাপা পড়ে ভূ-গর্ভস্থ চাপ ও তাপে কঠিন এবং তরল পদার্থে পরিণত হওয়া। যেমন- কয়লা, গ্যাস, তেল ইত্যাদি। | ১১৪ |

## দশম অধ্যায়: জাতীয় সম্পদ ও অর্থনৈতিক ব্যবস্থা

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| অপ্রতুল (Insufficient) | প্রয়োজনের বা চাহিদার তুলনায় কম। | ১১৯ |
| উৎপাদন (Production) | দ্রব্য বা সম্পদের এক অবস্থা থেকে অন্য অবস্থায় রূপান্তর। | ১১৬ |
| উদ্ভাবনী শক্তি (Innovative power) | মেধা ও সৃজনশীলতাকে কাজে লাগিয়ে নতুন কিছু আবিষ্কার করার ক্ষমতা। | ১১৮ |
| উদ্বৃত্ত মজুরি (Surplus wages) | শ্রমিকদের ন্যায্য মজুরি না দিয়ে মালিকপক্ষ মজুরি থেকে যে অতিরিক্ত অংশ রেখে দেয়। | ১২১ |
| খনিজ (Minerals) | খনি থেকে পাওয়া যায় এমন সম্পদ। সাধারণত খনি থেকে অর্থাৎ ভূগর্ভের গভীর থেকে এগুলো উত্তোলন করা হয়। | ১১৬ |
| চাহিদা (Demand) | পণ্যদ্রব্যের প্রয়োজনীয়তা। সাধারণ অর্থে কোনো দ্রব্য পাওয়ার আকাঙ্ক্ষা। | ১২১ |
| তত্ত্বাবধান (Supervision) | কোনো কিছু সাময়িকভাবে দেখা ও পর্যবেক্ষণ এবং প্রয়োজনীয় নির্দেশনা ও পরামর্শ দেওয়া। | ১১৮ |
| ধনতান্ত্রিক অর্থব্যবস্থা (Capitalist economy) | এই অর্থব্যবস্থায় সম্পদের ওপর ব্যক্তিমালিকানা প্রতিষ্ঠিত এবং প্রত্যেক ব্যক্তিই অবাধে উৎপাদন ও ভোগ করতে পারে। | ১২১ |
| পারিতোষিক (Remuneration) | শ্রমিকের তার কৃতিত্বপূর্ণ সেবা বা কাজের জন্য পারিশ্রমিকের চেয়ে যে পরিমাণ টাকা বেশি দেওয়া হয়। | ১২৪ |
| পুঁজিপতি (Capitalist) | মূলধনের মালিক। মুনাফা অর্জনের উদ্দেশ্যে যে ব্যক্তি উৎপাদন কাজে মূলধন বিনিয়োগ করে। | ১২০ |
| পেটেন্ট (Patent) | একচেটিয়া অধিকার। এ অধিকার দ্বারা কোনো উদ্ভাবক তার কোনো আবিষ্কার অন্য কারও দ্বারা তৈরি, ব্যবহার, বিক্রয় ও আমদানির ওপর আইনসিদ্ধ নিষেধাজ্ঞা আরোপ করতে পারে। | ১১৮ |
| বিপণন (Marketing) | পণ্যসামগ্রী ব্যবহারকারীর নিকট বা বিক্রয়ের জন্য বাজারে প্রেরণ। | ১২৪ |
| ভোক্তা (Consumer) | যে ব্যক্তি পণ্য বা সেবা ক্রয় করে। | ১২১ |
| মজুরি (Wages) | উৎপাদন কাজে নিয়োজিত ব্যক্তি শারীরিক ও মানসিক শ্রম এবং সেবাকর্মের বিনিময়ে যে অর্থ পায়। | ১২০ |
| মুক্তবাজার অর্থনীতি (Free market economy) | সম্পদের ব্যক্তিমালিকানা এবং উৎপাদন ও ভোগের ক্ষেত্রে ব্যক্তির সিদ্ধান্ত গ্রহণের স্বাধীনতা আছে এমন অর্থনৈতিক ব্যবস্থা। | ১২১ |
| মুনাফা (Profit) | উৎপাদিত পণ্য বিক্রি করে উৎপাদন খরচের চেয়ে যে অতিরিক্ত অর্থ পাওয়া যায়। | ১২০ |
| মূলধন (Capital) | সেই ধরনের সম্পদ যা সরাসরি ভোগ না করে কোনো কাজে লাগিয়ে বেশি উৎপাদনের চেষ্টা করা হয়। | ১২০ |
| যোগান (Supply) | প্রয়োজনীয় কোনো পণ্যের সরবরাহ। | ১১৭ |
| শ্রমিক (Workers) | সকল প্রকার উৎপাদন কাজে নিয়োজিত শারীরিক, মানসিক এবং সেবাকর্মের বিনিময়ে যারা অর্থ উপার্জন করে। | ১২০ |
| সমাজতন্ত্র (Socialism) | যে ব্যবস্থায় সম্পদ ও তত্ত্বের মালিকানা সামাজিক এবং রাষ্ট্রীয় নিয়ন্ত্রণে থাকে। | ১২২ |
| হস্তান্তরযোগ্যতা (Transferability) | একজনের কাছ থেকে বস্তুটি আরেকজনের পাওয়ার সম্ভাবনা। | ১১৭ |

**একাদশ অধ্যায়: অর্থনৈতিক নির্দেশকসমূহ ও বাংলাদেশের অর্থনীতির প্রকৃতি**

| অস্পৃশ্যত দ্রব্য (Intangible Goods) | এমন দ্রব্য, যা ধরা বা ছোঁয়া যায় না অথবা যার শারীরিক আকৃতি নেই। | ১৩৫ |
| উদ্বৃত্ত (Surplus) | প্রয়োজন বা ব্যবহারের পর রয়ে যাওয়া বাড়তি অর্থ বা সম্পদ। | ১৩৯ |
| কাঁচামাল (Raw materials) | এমন দ্রব্য বা পদার্থ, যা শিল্প কারখানায় প্রক্রিয়াজাতকরণের মাধ্যমে অন্য দ্রব্য বা পণ্যে পরিণত করা হয়। | ১৩৬ |
| চিরস্থায়ী বন্দোবস্ত (Permanent Settlement) | ১৭৯৩ সালে লর্ড কর্নওয়ালিস প্রণীত ইষ্ট ইন্ডিয়া কোম্পানির সরকার ও বাংলার ভূমি মালিকদের মধ্যে সম্পাদিত একটি স্থায়ী চুক্তি। | ১৪৯ |
| নির্দেশক (Indicator) | যা দ্বারা কোনো কিছুর অবস্থা বা স্তর বোঝানো হয়। | ১২৯ |
| বিনিয়োগ (Investment) | মুনাফা বা সুবিধা লাভের উদ্দেশ্যে কোনো কাজে অর্থ, শ্রম বা সময় ব্যয় করা। | ১৩১ |
| ভারী শিল্প (Heavy Industry) | যেসব শিল্পে বৃহৎ আকৃতির যন্ত্র ব্যবহারের মাধ্যমে বিপুল পরিমাণ দ্রব্য উৎপাদন করা হয়। | ১৩৭ |
| মধ্যবিত্তভোগী (Middleman) | যিনি উৎপাদনকারীদের কাছ থেকে পণ্য দ্রব্য ক্রয় করে মুনাফা লাভের বিনিময়ে ভোক্তাদের কাছে বিক্রি করেন। | ১৪০ |
| মূলধন (Capital) | ব্যবসা করার জন্য বা মুনাফা অর্জনের উদ্দেশ্যে ব্যবহৃত অর্থ। | ১৩০ |
| রিয়েল এস্টেট (Real estate) | জমি, ভবন বা স্থাপনা বিষয়ক সম্পত্তি। | ১৩৩ |
| শিল্পায়ন (Industrialization) | কোনো দেশ বা অঞ্চলে ব্যাপক হারে শিল্পের উন্নয়ন বা প্রসার ঘটা। | ১৩৪ |
| সঞ্চয় (Savings) | ব্যয় করার প্রয়োজন হয় না এমন অর্থ বা সম্পদ জমা করে রাখা। | ১৩৮ |
| সনাতন (Traditional) | সমাজে বহুদিন যাবৎ যা প্রচলিত। | ১৩৭ |
| সাক্ষরতা (Literacy) | কোনো কিছু পড়া ও লেখার সামর্থ্য। | ১৩৪ |
| সমীক্ষা (Survey) | কোনো কিছু ভালোভাবে পর্যবেক্ষণ বা জরিপ করে তার বিস্তারিত উল্লেখ করা। | ১৩২ |
| সুষম (Balanced) | সঠিক বা সমান অনুপাত। | ১৩২ |

## দ্বাদশ অধ্যায়: বাংলাদেশ সরকারের অর্থ ও ব্যাংকব্যবস্থা

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| আমানত (Deposit) | কোনো ব্যাংকে জমা রাখা অর্থ। | ১৫৮ |
| ইজারা (Lease) | ভাড়ার বিনিময়ে নির্দিষ্ট সময়ের জন্য কোনো সম্পদ ব্যবহারের ক্ষেত্রে দুই পক্ষের মধ্যে সম্পন্ন চুক্তিই হলো ইজারা। | ১৫৫ |
| জানমাল (Life and Property) | মানুষের জীবন ও সম্পত্তি। | ১৫৩ |
| পে-অর্ডার (Payment Order) | গ্রাহক যে শাখায় তার অর্থ জমা করে, সেই শাখা তার অর্থ প্রদান করে থাকে। অর্থাৎ ব্যাংক কর্তৃক তার নিজের শাখা থেকেই অর্থ পরিশোধ করার আদেশ দেওয়া। | ১৫৮ |
| প্রতিরক্ষা (Defense) | কোনো আক্রমণ বা বিপদ থেকে নিজেদের বা দেশকে রক্ষা করার কাল বা ক্ষমতা। | ১৫৬ |
| বন্ধক (Mortgage) | ব্যাংক বা অন্য কোনো আর্থিক প্রতিষ্ঠান থেকে ঋণ নেওয়ার জন্য মূল্যবান কোনো সম্পদ উক্ত প্রতিষ্ঠানের কাছে জমা রাখা। | ১৫৮ |
| বাজেয়াপ্তকরণ (Confiscation) | কোনো অপরাধের শাস্তিস্বরূপ কারো ব্যক্তিগত সম্পদ সরকারি ব্যবহারের উদ্দেশ্যে দখল করে নেওয়া। | ১৫৫ |
| ব্যাংক (Bank) | জনসাধারণের টাকা জমা রাখে এবং ঋণ প্রদান করে এমন প্রতিষ্ঠান। | ১৫৪ |
| ব্যাংক ড্রাফট (Bank-draft) | ব্যাংক কর্তৃক লিখিত ও স্বাক্ষরিত এমন একটি দলিল, যা কোনো নির্দিষ্ট ব্যক্তি বা প্রতিষ্ঠানকে নির্দিষ্ট পরিমাণ অর্থ চাহিবামাত্র প্রদানের জন্য একই ব্যাংকের অন্য শাখার ওপর শর্তহীনভাবে আদেশ দেওয়া হয়। | ১৫৮ |
| ভ্যাট (VAT- value added tax) | কোনো পণ্য ক্রয় বা সেবা গ্রহণের পর উক্ত পণ্য বা সেবার মূল্যের ওপর ক্রেতা যে বাড়তি অর্থ কর হিসেবে প্রদান করেন। | ১৫৪ |
| মুদ্রা সংকোচন (Deflation) | অর্থের মূল্য বেড়ে যাওয়া এবং দ্রব্য ও সেবার মূল্য কমে যাওয়া। | ১৫৯ |
| রাজস্ব (Revenue) | রাষ্ট্র পরিচালনার ব্যয় নির্বাহের জন্য সরকার বিভিন্ন খাত থেকে যে অর্থ আয় করে। | ১৫৪ |
| সমবায় (Cooperative) | কোনো সাধারণ উদ্দেশ্য অর্জনে পারস্পরিক সহযোগিতার মাধ্যমে কাজ করা। | ১৫৫ |
| সম্পূরক (Supplement) | উৎকর্ষ বা সম্পূর্ণতার জন্য যা যোগ করা হয়। | ১৫৪ |
| হুন্ডি (Hundi) | ব্যবসা-বাণিজ্য বা অর্থ লেনদেনের জন্য ব্যবহৃত আর্থিক দলিল বা ঋণ পরিশোধের প্রতিশ্রুতিপত্র। | ১৫৮ |

## ত্রয়োদশ অধ্যায়: বাংলাদেশের পরিবার কাঠামো ও সামাজিকীকরণ

| প্রজন্ম (Generation) | কোনো সমাজের প্রায় একই বয়সী বা প্রায় একই সময়ে জন্মগ্রহণকারী মানুষ। | ১৬৮ |

| যৌতুক (Dowry) | বিবাহের সময় কোনো এক পক্ষ অপরপক্ষকে যে অর্থ বা সম্পদ দিতে থাকে বা দেওয়ার জন্য চুক্তিবদ্ধ হয়। | ১৬৯ |

| সংগঠন (Organization) | যখন একাধিক ব্যক্তি কোনো নির্দিষ্ট উদ্দেশ্য অর্জনে একসাথে কাজ করে। | ১৬৫ |
| স্বাবলম্বী (Self-reliant) | যাকে অন্যের সাহায্যের ওপর নির্ভর করে চলতে হয় না। | ১৬৭ |
| হীনম্মন্যতা (Inferiority Complex) | অন্যদের তুলনায় নিজেকে ছোট বা কম জ্ঞানী বা কম আকর্ষণীয় মনে করা। | ১৬৭ |

| অবৈতনিক (Unpaid) | বিনা বেতনে কাজ করে এমন। | ১৮৩ |
| আত্মকর্মসংস্থান (Self-employment) | নিজেই নিজের কাজের ক্ষেত্র তৈরি বা কর্মসংস্থান করা। | ১৮৩ |
| উপরি কাঠামো (Superstructure) | কোনো সমাজ বা প্রতিষ্ঠানের মৌলিক ধারণা ও পদ্ধতি থেকে যে বিষয় বা পদ্ধতিগুলো সৃষ্টি হয়। | ১৭৯ |
| গড় আয়ু (Life expectancy) | একটি দেশে সাধারণত এক বছরে যে পরিমাণ মানুষ মারা যায় তাদের মোট আয়ুকে মোট মৃত্যুর সংখ্যা দ্বারা ভাগ করলে যে আয়ু পাওয়া যায়। | ১৮৩ |
| টর্নেডো (Tornado) | মেঘ ও পৃথিবী পৃষ্ঠের সাথে সংযুক্ত বায়ুস্তম্ভের আকারে সৃষ্টি প্রচণ্ড বেগে ঘূর্ণায়মান ঝড়। | ১৮০ |
| প্রবীণ (Elderly) | বাংলাদেশের প্রেক্ষাপটে ৬০ বছর বা তদূর্ধ্ব বয়সী মানুষ। | ১৮২ |
| প্রায়োগিক (Practical) | বাস্তব পরিস্থিতির আলোকে কোনোকিছুর ব্যবহার। | ১৮১ |
| ফ্যাক্স (Fax) | এমন একটি ইলেকট্রনিক বার্তা আদান-প্রদান ব্যবস্থা যার মাধ্যমে যেকোনো দলিল, তথ্য, ছবি, ডায়াগ্রাম, লেখা বা টেক্সট হুবহু কপি করে পাঠানো যায়। | ১৮১ |
| বৈশ্বিক উষ্ণায়ন (Global Warming) | গ্রিনহাউস গ্যাসের প্রভাবে পৃথিবীর তাপমাত্রা বৃদ্ধি পাওয়া। | ১৮০ |
| মৌল কাঠামো (Basic structure) | কোনো সমাজ বা প্রতিষ্ঠান যেসব বিষয়ের ওপর ভিত্তি করে গঠিত হয়। | ১৭৯ |
| শিল্পনগরী (Industrial city) | যেখানে বিভিন্ন ধরনের কলকারখানা এবং সেখানে উৎপাদিত পণ্যের ক্রয়-বিক্রয়ের ব্যবস্থা থাকে। | ১৮২ |
| সামাজিক দূরত্ব (Social Distance) | কর্মসংস্থান বা অন্য কোনো কারণে অন্য মানুষ থেকে দূরে অবস্থান করা। | ১৮২ |
| স্বয়ংসম্পূর্ণতা (Self-sufficiency) | নিজেই নিজের প্রয়োজন মেটানোর সক্ষমতা অর্জন করা। | ১৮১ |

## পঞ্চদশ অধ্যায়: বাংলাদেশের সামাজিক সমস্যা ও প্রতিকার

| পরিভাষা | সংজ্ঞা/ব্যাখ্যা | পাঠ্যবই পৃষ্ঠা |
| :--- | :--- | :---: |
| আন্ডার পাস (Underpass) | পথচারীর নিরাপদ রাস্তা পারাপারের জন্য মূল রাস্তার নিচ দিয়ে তৈরি বিকল্প রাস্তা। | ১৯৯ |
| উচ্চাভিলাষী (Ambitious) | যে কোনোকিছু অর্জনের মাত্রাতিরিক্ত ইচ্ছা পোষণ করে এবং যেকোনোভাবে তা অর্জনের চেষ্টা করে। | ১৯৯ |
| উটের জকি (Camel jockey) | আরব দেশগুলোতে উট দৌড় প্রতিযোগিতার সময় উটের মালিকরা উটের সওয়ার হিসেবে হালকা ওজনের শিশুদের ব্যবহার করে থাকে। এ শিশুদের উটের জকি বলা হয়। | ১৯০ |
| ওভারটেক (Overtake) | পেছনের যানবাহন কর্তৃক সামনের যানবাহনকে অতিক্রম করা। | ১৯৮ |
| কনভেনশন (Convention) | বিভিন্ন রাষ্ট্রের বা শাসকদের মধ্যে কোনো ব্যাপারে সমঝোতা (কিন্তু আনুষ্ঠানিক চুক্তি নয়)। | ১৯৫ |
| কিশোর অপরাধ (Juvenile delinquency) | কিশোর বয়সীদের দ্বারা সংঘটিত সমাজে বিদ্যমান মূল্যবোধ ও নিয়মনীতি বিরোধী কাজ। | ১৯৫ |
| কিশোর আদালত (Juvenile court) | যে আদালতে ১৮ বছরের কম বয়সী শিশু-কিশোর অপরাধীদের বিচার করা হয়। | ১৯৫ |
| গেজেট (Gazette) | সরকারের আদেশ ও বিভিন্ন রাষ্ট্রীয় পদে নিয়োগ সংক্রান্ত প্রজ্ঞপ্তি সম্বলিত সরকারি প্রকাশনা। | ১৯৬ |
| জেব্রাক্রসিং (Zebracrossing) | পথচারীর রাস্তা পার হওয়ার জন্য রাস্তার মাঝে আড়াআড়ি যে সাদা-কালো দাগ দেওয়া হয়। | ১৯৭ |
| ধাত্রী (Midwife) | যে নারী সন্তান প্রসবে সাহায্য এবং প্রসূতি ও নবজাতকের পরিচর্যা করে। | ১৯৬ |
| পাচার (Trafficking) | নিজ দেশের কোনোকিছু অবৈধ পন্থায় দেশের বাইরে পাঠানো বা বিক্রি করা। | ১৯০ |
| প্রতিবন্ধক (Obstacles) | যা বাধা বা বিঘ্ন সৃষ্টি করে। | ১৯৬ |
| ফতোয়া (Fatwa) | ইসলামি আইন-বিশেষজ্ঞ কর্তৃক শরিয়তের আলোকে কোনো সমস্যার সমাধান বা বিধান। | ১৮৯ |
| ফটকা কারবারি (Speculators) | সুযোগসন্ধানী এবং অধিক মুনাফা লোভী অসাধু ব্যবসায়ী। | ২০০ |
| ফিটনেস সার্টিফিকেট (Fitness certificate) | কোনোকিছু ব্যবহারের উপযোগী কি না তার সনদপত্র। | ১৯৮ |
| মূল্যবোধ (Values) | মানুষের ধ্যান-ধারণা, বিশ্বাস, লক্ষ্য ও উদ্দেশ্য, সংকল্প, আচার-আচরণ এবং কার্যাবলিকে যে ধারণা পরোক্ষভাবে নিয়ন্ত্রণ করে। | ১৮৮ |
| মৃত্যুহার (Mortality) | একটি নির্দিষ্ট সময়ে একটি দেশের মোট জনসংখ্যার মধ্যে প্রতি হাজারে যতজন মানুষের মৃত্যু হয় তার হার। | ১৯৬ |
| শিশু শ্রম (Child labour) | বাংলাদেশের শ্রম আইন অনুযায়ী ১৪ বছরের কম বয়সী শিশুদের কাজে লাগানো। | ১৮৮ |
| সহিংসতা (Violence) | যখন কোনো ব্যক্তি অপর ব্যক্তির সাথে সহিংস বা হিংসাত্মক বা আক্রমণাত্মক আচরণ করে। | ১৮৭ |
